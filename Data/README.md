# Dataset Description

This dataset contains detailed **sales transaction records** with both order-level and product-level information. It covers the entire sales process including order dates, customer details, territories, product categories, and financial metrics.

It provides a **comprehensive view of sales activity**, enabling analysis across **time, geography, product attributes, and revenue performance**.

---

## Key Fields

| Field | Description |
|-------|-------------|
| **SalesOrderID, SalesOrderDetailID** | Unique identifiers for each order and its line items. |
| **OrderDate, DueDate, ShipDate** | Dates related to order placement, due date, and shipping. |
| **CustomerID, TerritoryID, Territory** | Customer reference and geographic sales territory. |
| **SubTotal, TaxAmt, Freight, TotalDue** | Financial details including product subtotal, taxes, shipping cost, and final total amount. |
| **OrderQty** | Quantity of the product ordered. |
| **ProductID, Product** | Product identifier and product name. |
| **ProductCategoryID, Category** | Main product category (e.g., Bikes, Clothing, Accessories, Components). |
| **ProductSubcategoryID, Subcategory** | More specific grouping within categories (e.g., Road Bikes, Mountain Bikes, Bottles and Cages). |
| **Color** | Product color. |

---

## Use Cases

- Analyze **sales trends over time**.  
- Evaluate **territory-wise performance**.  
- Study **product-level sales and popularity**.  
- Compute **financial metrics** like revenue, tax, and shipping costs.  
- Identify **best-selling categories and subcategories**.
