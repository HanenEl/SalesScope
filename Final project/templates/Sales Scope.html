Project Overview

Summary and documentation of the Sales Forecasting and Optimization Project

About Sales Scope

Sales Scope is an integrated sales forecasting system that uses data analysis and machine learning to help businesses make better decisions regarding inventory, marketing, and sales management.

The system processes and analyzes sales data, then applies an AI model to predict future outcomes such as expected sales or Due Days.

Project Purpose

  • Analyze historical sales data
  • Identify patterns, trends, and correlations
  • Accurately forecast demand and future sales
  • Enhance business operations and enable data-driven decisions

System Components

Dashboard

The interactive dashboard displays the most important sales metrics, including:

  • Total Sales
  • Total Transactions
  • Average Order Value
  • Top Territories
  • Sales by Territory / Category
  • Top 10 Products
  • Monthly Trends
  • Heatmap (Category vs Territory)

The dashboard updates automatically whenever new data is uploaded.

Upload & Predict

Allows users to upload CSV sales data. The system then:

  • Processes the uploaded data
  • Applies the AI prediction model
  • Generates the Predicted Due column
  • Shows a preview of the first 5 predicted rows
  • Allows downloading the full results as a CSV file

Supports large files up to 50MB.

Manual Input

Designed for cases where no CSV file is available. Users can:

  • Add any number of input rows
  • Edit values directly
  • Run Predict All instantly
  • Receive results immediately

Includes built-in validation to ensure input correctness for accurate predictions.
